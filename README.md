## What it does

`main.py` writes one funny passive-aggressive note from a smart fridge to its
owner — a single line — to `/output/entry.txt`.

> The door alarm logged your 2 a.m. ice cream. I told it to keep quiet. You're welcome.

## Run

```sh
python3 main.py
```

Pure Python standard library only, deterministic, no network access.
